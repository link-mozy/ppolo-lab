# PPOLO 워치 화면 시나리오 초안

> 목적: Apple Watch MVP에서 **기록 모드** 와 **경쟁 모드** 의 최소 화면 흐름을 먼저 고정한다.
> 이 문서는 세부 디자인 시안이 아니라, 어떤 상태에서 어떤 정보와 버튼이 보여야 하는지 정리하는 초안이다.

---

## 1. 설계 원칙

- 워치는 모바일보다 정보량을 줄이고, **현재 해야 할 행동 1개** 를 가장 크게 보여준다.
- 화면 전환은 최소화하고, 버튼은 크게 배치한다.
- 기록 모드와 경쟁 모드는 **완전히 다른 흐름** 으로 분리한다.
- 런닝은 실시간성, 운동기록은 입력 편의성이 우선이다.
- 네트워크가 불안정하더라도 현재 기록 상태는 워치에서 즉시 확인 가능해야 한다.

---

## 2. 기록 모드 시나리오

### 2.1 운동기록 시나리오
대상: 헬스/웨이트/일반 운동 기록

#### 시나리오 A. 운동 시작 전 빠른 진입
- 워치 홈에서 `운동기록` 진입
- 최근 사용한 운동 부위 / 종목을 우선 노출
- `새 기록 시작` 또는 `최근 기록 이어서` 중 선택

#### 시나리오 B. 운동 기록 입력
- 운동 부위 선택
- 운동 종목 선택
- 무게 입력
- 횟수 입력
- 세트 수 입력
- 선택 항목:
  - 휴식
  - 메모
  - RPE
- 입력 완료 후 `저장` 버튼으로 한 세트 저장

#### 시나리오 C. 세트 반복 기록
- 저장 후 다음 세트로 빠르게 이동
- 방금 입력한 값 유지
- 무게 / 횟수만 빠르게 수정 가능
- 세트가 끝나면 `다음 세트` 또는 `종료`

#### 시나리오 D. 휴식 타이머
- 세트 저장 직후 휴식 화면으로 전환 가능
- 남은 휴식 시간 표시
- `재개` 또는 `종료` 제공
- 휴식은 선택 입력이므로, 사용자가 원하면 건너뛸 수 있음

#### 시나리오 E. 운동 종료
- `종료` 시 오늘 기록 요약 노출
- 저장된 세트 수, 총 운동 시간, 메모 요약 표시
- 최종 저장 전 확인

### 2.2 운동기록 화면에 필요한 핵심 요소
- 운동 부위
- 운동 종목
- 무게
- 횟수
- 세트 수
- 휴식(선택)
- 메모(선택)
- RPE(선택)

## 3. 런닝기록 시나리오

### 3.1 수동 런닝기록
대상: 걷기/러닝 수동 입력 또는 보정 기록

#### 시나리오 A. 빠른 수동 입력
- `런닝기록` 진입
- 기본 필수값은 `거리` 와 `시간`
- 저장 전 보조값(메모, 페이스 확인) 노출 가능

#### 시나리오 B. 자동 수집 기록 확인
- 워치가 센서 기반으로 거리/시간/GPS를 수집
- 현재 페이스와 누적 거리를 큰 글씨로 표시
- 사용자는 중간에 일시정지 / 재개 가능
- 기록 종료 시 최종 값 확인 후 저장

#### 시나리오 C. 보정 확인
- 센서값과 서버 정규화값이 다를 수 있으므로
- 저장 전 "이 값으로 저장할지" 확인 화면 노출 가능

### 3.2 런닝기록 화면에 필요한 핵심 요소
- 거리
- 시간
- 현재 페이스
- 일시정지 / 재개
- 종료
- 선택적으로 GPS / 심박 / 경로 요약

---

## 4. 경쟁 모드 시나리오

### 4.1 대기실 시나리오
대상: 경쟁방 입장 후, 실제 기록 시작 전

#### 시나리오 A. 대기실 진입
- 경쟁방 이름, 목표 거리, 마감 시간, 현재 참가자 상태 노출
- `준비완료` 버튼 제공
- 방장이 설정한 비밀번호 입력이 필요한 경우 먼저 처리

#### 시나리오 B. 준비완료
- 준비 상태가 되면 내 상태를 크게 표시
- 시작 전까지는 랭킹 화면에 노출하지 않거나 별도 대기 영역에 둠
- 다른 참가자의 준비 상태를 간단히 보여줌

#### 시나리오 C. 방장 강제 시작 대응
- 방장이 강제 시작하면 미준비자는 퇴출될 수 있으므로
- 경고 상태 또는 즉시 전환 상태를 명확히 노출

### 4.2 진행 중 시나리오

#### 시나리오 D. 경쟁 기록 시작
- 사용자가 `기록 시작`을 누르면 런닝 기록 화면으로 진입
- 현재 순위, 예상 순위, 앞 사람과의 차이 등을 최소 정보로 표시

#### 시나리오 E. 경쟁 중 일시정지
- `일시정지` / `재개` / `종료`가 가장 큰 버튼이어야 함
- 누적 무료 일시정지 시간을 초과하면 패널티가 반영된다는 안내 필요
- 남은 무료 pause 시간이 있으면 함께 표시

#### 시나리오 F. 실시간 랭킹 확인
- 내 순위
- 바로 앞 사람과의 차이
- 1등과의 차이
- 목표 도달 예상 시각(ETA)
- 현재 거리 / 유효 시간

### 4.3 종료 시나리오

#### 시나리오 G. 완주
- 목표 거리 도달 시 완주 화면 표시
- 완주 시간, 최종 순위, 패널티 반영 여부 확인
- 결과 저장 완료 상태 노출

#### 시나리오 H. 마감 도달
- 마감 시각에 도달하면 기록 종료 또는 결과 확인 화면으로 전환
- 미완주 / 실격 / DNF 상태는 별도 메시지로 표시

---

## 5. 화면 우선순위 제안

워치 MVP는 다음 우선순위로 만드는 것이 좋다.

1. 기록 시작 / 종료
2. 일시정지 / 재개
3. 현재 거리 / 시간 / 페이스
4. 운동기록 입력 최소 흐름
5. 경쟁방 대기실 / 준비완료 / 실시간 랭킹

---

## 6. 다음에 더 구체화할 항목

- 운동기록 세트 입력을 **몇 단계로 나눌지**
- 런닝기록에서 **자동 모드와 수동 모드 전환 방식**
- 경쟁 중 랭킹 화면에서 **어느 정도까지 정보를 보여줄지**
- 워치에서 입력 가능한 필드와 모바일 전송 여부
- 오프라인 상태에서 임시 저장 허용 여부
