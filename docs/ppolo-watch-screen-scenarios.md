# PPOLO 워치 화면 시나리오 초안

> 목적: Apple Watch MVP에서 워치는 **입력 단말이 아니라 최소한의 리모컨 + 상태 모니터링 화면** 으로 동작해야 한다.
> 이 문서는 워치에서 어떤 상태를 보여주고, 어떤 버튼만 제공해야 하는지 정리한 초안이다.

---

## 1. 설계 원칙

- 워치는 모바일보다 정보량을 줄이고, **현재 상태를 빠르게 확인** 하는 데 집중한다.
- 워치는 복잡한 입력을 받지 않는다.
- 워치에서의 역할은 **기록/경쟁을 직접 조작하는 최소 버튼 리모컨** 이다.
- 세부 입력, 긴 텍스트, 종목 선택, 무게/횟수 입력은 **모바일에서만 처리** 한다.
- 진행 중 화면은 현재 상태를 한눈에 보여주는 **모니터링 화면** 이어야 한다.

---

## 2. 워치 공통 원칙

- 한 화면에는 한 행동만 배치한다.
- 버튼은 최대 2~3개 수준으로 제한한다.
- 텍스트는 짧게, 숫자는 크게 표시한다.
- 긴 설명 대신 상태 라벨을 보여준다.
- 상세 수정은 모바일로 넘긴다.

---

## 3. 운동기록 모드

운동기록에서 워치는 **입력 화면이 아니라 제어 화면** 이다.

### 3.1 운동기록 시작 전
- `시작`
- `최근 상태 확인`
- `종료`

워치에서는 운동 부위, 종목, 무게, 횟수, 세트 수를 입력하지 않는다.

### 3.2 운동 진행 중
- `일시정지`
- `재개`
- `종료`

### 3.3 운동 진행 중 표시 정보
- 현재 상태: `운동 중` / `일시정지 중`
- 누적 운동 시간
- 현재 세트 진행 여부
- 필요 시 휴식 타이머 상태

### 3.4 운동 종료
- `종료`
- `상태 확인`

운동 상세 기록은 모바일에서만 저장/수정한다.

---

## 4. 런닝기록 모드

런닝기록에서 워치는 시작/중지/일시정지용 리모컨이다.

### 4.1 런닝 시작 전
- `시작`
- `상태 확인`
- `종료`

### 4.2 런닝 진행 중
- `일시정지`
- `재개`
- `종료`

### 4.3 런닝 진행 중 표시 정보
- 현재 상태: `러닝 중` / `일시정지 중`
- 현재 거리
- 누적 시간
- 현재 페이스
- 센서 연결 상태

### 4.4 런닝 종료
- `종료`
- `상태 확인`

수동 입력은 워치에서 받지 않으며, 거리/시간의 최종 저장은 모바일 또는 서버 동기화 결과를 따른다.

---

## 5. 경쟁 모드

경쟁 모드에서 워치는 **현재 방 상태를 확인하고, 경쟁 시작 전/중/종료를 최소 버튼으로 제어하는 화면** 이다.

### 5.1 경쟁 대기실
대상: 경쟁방 입장 후, 실제 기록 시작 전

#### 표시 정보
- 경쟁방 이름
- 목표 거리
- 마감 시간
- 내 상태: `대기 중` / `준비완료`
- 현재 참가자 상태 요약

#### 버튼
- `준비완료`
- `상태 확인`
- `나가기`

#### 원칙
- 워치에서 기록 시작을 직접 입력하는 흐름은 두지 않는다.
- 먼저 현재 경쟁방의 준비 상태가 맞는지 확인한다.
- 준비완료 이후 실제 경쟁 시작은 방 규칙에 따른다.

### 5.2 경쟁 진행 중
#### 표시 정보
- 현재 상태: `경쟁 중`
- 내 상태: `running` / `paused` / `finished`
- 현재 거리
- 현재 페이스
- 1등과의 차이
- 바로 앞 사람과의 차이
- ETA
- 남은 무료 pause 시간

#### 버튼
- `일시정지`
- `재개`
- `종료`
- `상태 확인`

#### 원칙
- 워치는 경쟁 기록을 직접 입력하지 않는다.
- 워치는 **현재 어떤 상태인지 모니터링** 하고, 리모컨 역할만 수행한다.
- 랭킹 상세는 모바일에서 확인한다.

### 5.3 경쟁 종료
#### 표시 정보
- 현재 상태: `완주` / `마감 도달` / `DNF` / `실격`
- 최종 시간
- 최종 순위
- 패널티 반영 여부

#### 버튼
- `종료`
- `결과 확인`

---

## 6. 화면 우선순위 제안

워치 MVP는 다음 우선순위로 만드는 것이 좋다.

1. 현재 상태 표시
2. 시작 / 일시정지 / 재개 / 종료
3. 준비완료
4. 거리 / 시간 / 페이스
5. 경쟁 중 최소 랭킹 요약

---

## 7. 다음에 더 구체화할 항목

- 워치에서 `상태 확인`이 보여줘야 하는 세부 항목
- 경쟁 대기실에서 방장/참가자 권한별 버튼 차이
- 일시정지 허용 잔여 시간 표시 방식
- 서버 동기화 실패 시 워치가 보여줄 최소 경고 문구
