PPOLO / DESIGN DOCUMENT

디자인 정의서

PPOLO의 디자인은 *넷플릭스처럼 강한 레드/블랙 대비*를 기본으로 하고, 텍스트는 *화이트 중심*으로 정리합니다. 전체 인상은 다크하고 시네마틱하게 유지하되, 핵심 정보와 행동 버튼은 한눈에 읽히도록 설계합니다.

공개 경로: design.html 톤: Red / Black / White 검토 대상: UI / UX / Brand

1. 디자인 방향

검은 배경 위에 선명한 레드 포인트를 얹고, 모든 텍스트는 화이트로 읽히게 한다.

이 문서는 보기 좋은 포스터가 아니라, 실제 앱을 만들 때 흔들리지 않도록 기준을 정리한 문서입니다. 홈, 기록, 경기, 결과 화면이 모두 같은 세계관에 있지만, 각 화면의 역할은 분명히 달라야 합니다.

02 / Colors, type, surfaces

색 / 타이포 / 표면

레드와 블랙만으로도 충분히 강한 인상을 만든다.

표면과 대비

배경은 완전한 블랙에 가깝게 두고, 카드와 패널은 한 톤만 밝게 구분한다. 장식성 그라데이션은 줄이고, 정보 계층은 텍스트 크기와 여백으로 만든다.

#E50914 #FFFFFF #111111 #B9B9B9

Typography

  • 제목은 굵고 짧게, 본문은 길어도 읽기 쉽게 쓴다.
  • 숫자와 상태는 일반 본문보다 더 큰 크기로 보여준다.
  • 화이트를 기본으로 두고, 강조는 레드로만 제한한다.

Spacing

  • 섹션 간격은 충분히 크게, 카드 내부는 단정하게 유지한다.
  • 모바일 기준 터치 타깃은 44px 이상을 유지한다.
  • 여백이 부족하면 내용이 아니라 구조를 먼저 고친다.

03 / Layout rules

레이아웃과 정보 우선순위

화면마다 가장 먼저 읽혀야 하는 정보만 상단에 둔다.

홈

현재 상태, 빠른 시작, 최근 기록, 공지처럼 사용자가 바로 행동할 요소를 앞에 둔다.

기록

리스트와 상세를 분리하고, 입력/수정은 강한 버튼 한두 개만 남긴다.

경기 / 결과

랭킹, 남은 시간, 내 상태를 크게 보여주고 나머지는 보조 정보로 낮춘다.

04 / Component language

컴포넌트 정의

각 컴포넌트의 목적, 형태, 상태를 짧고 명확하게 적는다.

Primary button

가장 중요한 행동 1개만 담당한다. 배경은 레드, 텍스트는 화이트, 라벨은 짧게 유지한다.

Secondary button

보조 행동을 위한 버튼이다. 표면은 다크, 경계선은 얇게, 레드 사용은 최소화한다.

Status pill

상태를 먼저 읽히게 한다. 텍스트가 우선이고 색은 보조 신호 역할만 맡는다.

Card / Panel

  • 목적: 정보 묶음, 설정 묶음, 요약 묶음을 분리한다.
  • 구조: 제목 → 본문 → 보조 액션 순서로 정리한다.
  • 상태: 기본 / 선택됨 / 비활성 / 강조됨을 구분한다.
  • 규칙: 카드 자체가 장식이 아니라 정보 컨테이너가 되게 한다.

Ranking row / Input

  • 랭킹 행은 순위 숫자, 이름, 점수, 상태를 한 줄에 압축한다.
  • 입력은 라벨과 도움말을 분리해 읽기 쉬운 구조를 유지한다.
  • 오류·비활성·로딩 상태는 문구로 먼저 보여준다.
  • 탭 가능한 영역은 모바일에서 충분히 크게 잡는다.
05 / Brand assets

로고와 아이콘의 사용 기준

브랜드 자산은 장식이 아니라 식별 장치로 다룬다.

사용 원칙

  • 로고는 앱 아이콘, 상단 브랜드 영역, 스플래시, 공유 썸네일처럼 “PPOLO”를 먼저 인식시켜야 하는 곳에 둔다.
  • 모바일 헤더는 로고 뒤에 텍스트 PPOLO를 붙여 “(로고) PPOLO” 형태로 보여준다.
  • 탭 아이콘은 홈 / 기록 / 경기 / 마이의 4개 주요 진입점을 구분하는 용도로만 사용한다.
  • 아이콘은 이미지 자체만 보이게 하고, 별도 테두리나 512x512 PNG 표기는 사용하지 않는다.
  • 활성 상태는 레드 계열, 비활성 상태는 화이트/그레이 계열로 대비를 둔다.

06 / State and motion

상태는 색보다 문구로 먼저 보이게

움직임은 적게, 변화는 분명하게.

상태 규칙

  • 진행 중: 시간, 진행 바, 현재 순위를 묶어서 보여준다.
  • 대기 중: 시작 조건과 남은 시간을 분리해서 보여준다.
  • 완료: 결과와 다음 행동만 남겨 조작을 줄인다.

모션 규칙

  • 전환은 짧고 부드럽게, 과장된 연출은 피한다.
  • 랭킹 변화는 숫자 중심으로 안정적으로 보여준다.
  • 운동 중 화면은 시선을 빼앗는 장식을 최소화한다.
07 / Review checklist

검토 체크리스트

이 문서는 멋보다 적용 가능성이 먼저다.

확인 기준
  • 검은 배경 + 레드 포인트 + 화이트 텍스트로 일관되는가?
  • 버튼/상태/중요 정보만 눈에 띄는가?
  • 홈, 기록, 경기, 결과가 같은 시스템 안에서 읽히는가?
  • 문서가 실제 디자인 기준서처럼 보이는가?
남겨둔 질문
  • 메인 레드를 더 진하게 할지, 현재 수준으로 유지할지
  • 카드의 표면감을 더 줄이고 평면적으로 갈지
  • 와이어프레임도 같은 레드/블랙 체계로 더 맞출지
