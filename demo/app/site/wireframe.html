PPOLO / SCREEN WIREFRAME

화면 설계서 초안

이 문서는 디자인 정의서의 기준을 그대로 가져와, 실제 앱이 실행됐을 때 보일 법한 화면 구조를 정리한 와이어프레임입니다. 색보다 구조가 중요하지만, 문서 전체는 *넷플릭스식 다크/레드/화이트 톤*으로 통일합니다.

1. 플로우

진입 → 홈 → 기록 / 매치 → 각기 다른 입력 흐름

화면을 하나의 단일 경로로 보지 않고, 사용자가 실제로 들어갈 수 있는 주요 시나리오를 분리해 배치했습니다. 헬스는 날짜를 먼저 입력하고 운동 항목을 쌓는 방식, 러닝은 기록 입력 방식, 매치는 대기실과 측정 중, 결과까지 이어지는 방식으로 다룹니다.

02 / User journey

대표 플로우

앱에서 실제로 자주 쓰는 경로를 분리해서 보여준다.

A. 진입 → 홈 → 기록 → 헬스기록

날짜를 먼저 입력하고, 부위·운동명·세트·중량·횟수를 하나씩 추가한다.

B. 진입 → 홈 → 기록 → 러닝

러닝 기록을 입력하고 저장하는 독립 경로다.

C. 진입 → 홈 → 매치 → 대기실 → 매칭중 → 결과

방에 들어가 대기하고, 측정 중에는 실시간 상태를 확인한 뒤 결과를 본다.

보조. 워치

04 / Notes

버튼 동작과 플로우 검토

각 버튼이 어디로 가는지 먼저 고정한다.

구조 체크

홈, 방, 기록 분기, 매치중, 결과, 워치가 각각 다른 목적을 가지므로 같은 틀을 억지로 쓰지 않도록 했다.

버튼 체크

초대하기는 초대 모달, 시작하기는 방장 전용 시작 상태, 러닝 저장/헬스 저장은 각각의 기록 입력 화면으로 연결한다.

분기 체크

기록 탭 진입 후에는 먼저 러닝/헬스를 선택하고, 헬스는 날짜 입력 → 운동 한 줄 추가 흐름으로 이어진다.
