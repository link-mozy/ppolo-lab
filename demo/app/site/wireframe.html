PPOLO / SCREEN WIREFRAME

화면 설계서 초안

이 문서는 디자인 정의서의 기준을 그대로 가져와, 실제 앱이 실행됐을 때 보일 법한 화면 구조를 정리한 와이어프레임입니다. 색보다 구조가 중요하지만, 문서 전체는 *넷플릭스식 다크/레드/화이트 톤*으로 통일합니다.

공개 경로: wireframe.html 상태: 즉시 반영 레이아웃: 앱 실행형

1. 플로우

진입 → 홈 → 매치방 → 러닝 기록 → 매치중 → 결과 → 워치

화면을 따로 보여주지 않고, 사용자의 실제 이동 순서대로 배치했습니다. 러닝 기록과 매치중 화면은 업로드한 이미지처럼 같은 시각 언어를 공유하되, 매치중에서는 우측 상단 랭킹 오버레이가 추가됩니다.

홈

오늘의 상태와 빠른 시작을 보여주는 첫 화면

매치방

입장 전 정보와 참가자, 시작 조건을 보여주는 화면

러닝 기록 / 매치중

지도, 기록 요약, 핵심 버튼을 크게 보여주고 랭킹은 작게 얹는 화면

워치

핵심 조작만 남긴 최소 UI

02 / User journey

상세 화면 흐름

문서 구조 자체가 앱 시나리오를 따라가도록 정리했다.

1. 홈

오늘의 운동 상태와 매치 진입을 확인한다.

2. 방 입장

방 정보, 참가자, 시작 조건을 본다.

3. 러닝 기록

업로드한 이미지처럼 지도와 기록 요약, 제어 버튼을 배치한다.

4. 매치중

우측 상단의 작은 랭킹 오버레이로 현재 순위를 확인한다.

5. 결과

최종 시간과 순위를 정리한다.

6. 워치

핵심 조작만 남긴 보조 화면을 사용한다.

04 / Notes

이 와이어프레임에서 확인하려는 것

화면 수보다 구조의 적합성이 중요하다.

구조 체크

홈, 방, 러닝 기록, 매치중, 결과, 워치가 각각 다른 목적을 가지므로 같은 틀을 억지로 쓰지 않도록 했다.

디자인 체크

와이어프레임이지만 앱처럼 보이기 위해 탭바, 카드, 진행 바, 버튼 위치를 실제 화면처럼 배치했다.
