PPOLO / WIREFRAME DOCUMENT

화면 설계서 초안

이 페이지는 주요 화면의 구조, 정보 우선순위, 버튼 위치, 이동 흐름을 와이어프레임 형태로 확인하기 위한 초안입니다. 디자인보다 먼저 구조가 타당한지 보는 용도입니다.

공개 경로: wireframe.html 주요 화면 18개 확인 포인트: 구조 · 플로우 · 누락

설계 기준

접속 → 로그인 → 홈 → 기록/경쟁 → 결과 확인 흐름으로 읽히게 한다.

화면마다 사용자의 목적이 다르므로, 같은 레이아웃을 억지로 반복하지 않고 목적에 맞는 정보 덩어리를 배치합니다. 특히 경쟁 화면은 대기실과 측정 중 화면을 분리하는 것이 핵심입니다.

상태 표현

대기 / 진행 / 경고 / 종료는 색보다 문구가 먼저 읽히게 둡니다.

버튼 수

워치와 런닝 화면은 조작 버튼이 많지 않도록 최소화합니다.

정보 우선순위

홈은 현재 상태, 경쟁은 랭킹/마감, 기록은 입력/저장 순서로 배치합니다.

구조 검토 포인트

한 화면에 서로 다른 목적이 섞여 있지 않은지, 그리고 사용자가 어디서 무엇을 해야 하는지가 첫눈에 보이는지 확인합니다.

플로우 검토 포인트

접속과 로그인, 홈 진입, 기록 작성, 경쟁 참여, 결과 확인 사이에 불필요한 되돌아감이 없는지 봅니다.

현재 초안에서 더 확정하면 좋은 항목

홈의 공지 비중, 경쟁방 생성 기본값, 로그인 실패 메시지 카피, 워치 상태 문구 압축 여부.

이 페이지의 용도

디자인 확정 전 구조 검토용입니다. 픽셀 완성도보다 화면 분리와 플로우가 맞는지 보는 것이 우선입니다.
