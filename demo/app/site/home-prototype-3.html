처음 보는 사용자에게 서비스 구조를 이해시키는 설명형 홈입니다. 기록, 경쟁, 최종 결과의 관계를 문장과 흐름으로 읽게 하는 방향입니다.

처음 보는 사용자 기준
핵심 목표무엇을 먼저 해야 하는지 바로 이해시키기

시선 처리큰 문구 → 단계 → 자세한 설명 순서
1

기록 시작

처음 홈에 들어오면 오늘 운동을 기록할 수 있다는 사실이 먼저 보여야 합니다.

2

경쟁방 참여

공개방 목록, 입장 확인, 대기실 진입이 하나의 흐름으로 연결되어야 합니다.

3

랭킹 확인

실시간 랭킹과 최종 랭킹은 다르게 보이므로, 홈에서 차이를 먼저 설명합니다.

홈 화면에서 반드시 이해되어야 하는 것

요약 정보와 상세 설명을 분리하는 구조

첫 화면 문장

“운동 기록과 경쟁을 한 번에”처럼 서비스의 목적을 말하는 문장이 먼저 들어가야 합니다.

중간 영역

기능 버튼과 핵심 상태를 카드로 보여주고, 사용자가 무엇을 할 수 있는지 정리합니다.

숨겨진 설명

초기에는 간단히 보이지만, 필요하면 각 기능의 규칙과 예외를 더 자세히 펼쳐볼 수 있어야 합니다.

보기 방식

처음 보는 사람은 요약만, 익숙한 사람은 상세를 펼쳐보는 방식이 가장 안정적입니다.

자주 묻는 흐름

방 목록에서 선택하고, 입장 전 확인을 거쳐 대기실로 들어갑니다. 사용자가 실수로 들어가는 것을 막는 흐름입니다.

ETA와 보조 지표를 기준으로 정렬하고, 측정 대기나 DNS 같은 상태는 다른 영역으로 분리합니다.

완주자는 숫자 순위 리스트에, 순위 외 결과는 접힘 섹션에 따로 보여주어 화면의 성격을 분리합니다.
