PPOLO / demo.ppolo.org

정적 프로토타입 데모

HTML · CSS · JS만으로 만드는 화면 예시용 공간입니다. 필요한 시나리오를 말해주면 이 공간에 바로 추가합니다.

Cloudflare Tunnel Docker Port 28080

현재 데모 목적

홈 화면, 매치방, 실시간 랭킹, 최종 랭킹, 워치 시나리오를 빠르게 보여주는 공간

이 데모는 실제 서비스의 축소판이 아니라, 요구사항 검토와 화면 의사결정을 위한 프로토타입 전용 페이지입니다.

기본 포트 28080 서버 내부 앱 포트
노출 방식 Tunnel 공인 IP 없이 외부 공개
관리 위치 demo/ 프로토타입 전용 폴더
기본 용도 Static UI HTML + CSS + JS
